
# 🎬 Movie App

## 📌 About Project
This is a Movie App built using React JS. Users can explore popular movies, search for movies, and view movie details.

## 🚀 Features
- View Popular Movies
- Search Movies
- Movie Details
- API Integration
- Loading and Error Handling
- Responsive Design

## 🛠️ Technologies Used
- React JS
- JavaScript
- Redux
- HTML
- CSS
- Bootstrap
- Movie API

## ⚙️ Installation

### 1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Go to Project Folder
```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run the Project
```bash
npm start
```

## 🔑 API Configuration
Add your API key in the `.env` file.

```env
REACT_APP_API_KEY=your_api_key
```
